# Electrical Components Database

A simple Python project for managing electrical components.

## Features

- Show all components
- Add new components
- Delete components
- Input validation
- Menu-driven interface

## Technologies

- Python 3
- Dictionary
- Loops
- Functions
- Exception Handling

## Future Improvements

- Search component
- Edit component
- Save data to JSON
- Load data from JSON
- Graphical User Interface (GUI)
